# @ddd-store/web-react

React 19 implementation of the DDD Store web client.

See [apps/web/README.md](../README.md) for multi-framework architecture.

```bash
npm run dev -w @ddd-store/web-react
npm run build -w @ddd-store/web-react
npm run test -w @ddd-store/web-react
```

Features live under `src/features/<slice>/` and consume `@ddd-store/web-shared`.
